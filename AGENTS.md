# Установочный пакет Oblako — точка входа для агента

Эта папка — **контур ПК**: расшифровка встречи, разбор планёрки, подготовка к
встрече по карте проектов и срез задач людей за период. Кода сервера здесь
нет. Отвечай **по-русски**; человек напротив — руководитель отдела, а не
программист.

**Первым делом, до всего остального:**

```
python install_skills.py
```

Он раскладывает команды из `Скиллы/` по папкам клиентов. Без него ни одной
команды не существует, и попросить «настрой пакет» будет нечего. После него
клиента надо **перезапустить** — иначе он не увидит новых команд.

**Python не найден — это не тупик, а первый шаг установки.** На свежей машине его
может не быть вовсе: тогда читай `Скиллы/ustanovka.md` напрямую и веди человека
по нему с шага 1 — Python и git ставишь ТЫ сам, не отправляя его на сайты. То же
касается git: без него не будет работать «обнови пакет».

Команд семь, и всё, что делает пакет, делают они:

| Скажет человек | Инструкция |
|---|---|
| «настрой пакет» | `Скиллы/ustanovka.md` — установка с нуля |
| «подключи автомат» | `Скиллы/avtomat.md` — личная рутина в облаке, которая расшифровывает записи сама и разбирает планёрку отдела; уже заведённую — обновляет (нужна подписка claude.ai; на Codex — нет) |
| «разбери планёрку» | `Скиллы/razbor.md` — весь путь до итога в чате отдела |
| «разбери встречу с <кем> <когда>» | тот же `Скиллы/razbor.md` — встречу 1:1 или созвон находит по серверу сам: карточка, готовый текст из Библиотеки или запись |
| «расшифруй запись» | `Скиллы/transkript.md` — только текст встречи |
| «подготовься к совету», «подготовься к планёрке» | `Скиллы/podgotovka.md` — позиция по карте проектов, файл под именем автора в Библиотеке |
| «собери повестку» | `Скиллы/povestka.md` — повестка встречи из подготовок участников, в Библиотеку под именем организатора |
| «обнови пакет» | `Скиллы/obnovlenie.md` — свежая версия и проверка |

Клиент перезапустить нечем или команды всё равно не видны — **прочитай нужный
файл из `Скиллы/` и исполняй его напрямую**. Инструкция там полная, пересказ по
памяти не годится.

**Срез — что сделали люди за период.** Скилла у него нет, есть скрипт. Фразы
вроде «выгрузи закрытые задачи розницы за неделю», «что сделал отдел с прошлой
пятницы», «что закрыла Оля за 16–17 сентября» — это он, а не «сервер такого не
умеет»:

```
python fetch_slice.py --from <ГГГГ-ММ-ДД> --to <ГГГГ-ММ-ДД> [--team <отдел>]
```

- Даты считаешь сам, обе включительно, период не длиннее 92 дней: «за неделю» —
  семь дней по сегодня, «с прошлой пятницы» — с той пятницы по сегодня.
- Отдел назван — `--team` с его именем; не назван — без него (все свои люди).
  Назван человек — выгрузи без отдела и возьми из файла только его.
- Скрипт печатает путь к файлу и итог. В файле у каждого человека: `closed` и
  `dropped` — закрытое и снятое по дням, `moved` — перенесённое, `now` — что
  висит сейчас (`overdue`, `open`, `no_due`). Покажи человеку словами, по людям
  и по дням, а не JSON.
- `meeting_origin` у задачи — встреча, на разборе которой она родилась:
  `department: true` — «с планёрки 16 сентября», иначе «со встречи 16
  сентября» (совет, 1:1 и разовая встреча — не планёрки); число — из `date`. У
  новой задачи со встречи автора нет (`new_from` пуст): «новая · с планёрки 16
  сентября», а не «от <кого>».
- `assignments_only: true` у человека — срез сужен: он собственник, и видны
  только поручения ему от того, кто выгружал, и — если выгружал собственник —
  задачи со встреч, где были оба. Так и скажи («показаны только ваши поручения
  и задачи с общих встреч»), не выдавай это за всё, что он сделал.
- «Сервер ещё не умеет срез» — передай как есть: это к владельцу системы, пакет
  обновлять не нужно.

**Состояние установки — не в разговоре, а здесь:**

```
python setup_check.py            # --offline: то же самое без сети
```

Она проверяет заново, а не вспоминает: Python, `.env`, ключ Deepgram, папки,
подключённые команды, живую связь с сервером и совпадение версий. Код 0 —
готово, 1 — есть что чинить, и у каждой находки назван следующий шаг.

Ключи (`.env`) в чат не проси и в ответах не повторяй. Краткая инструкция для
человека — `README.md`.
