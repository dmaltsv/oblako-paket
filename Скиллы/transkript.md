# Расшифровка записи

Только текст. Задачи из разговора эта команда не извлекает и на сервер ничего не
отправляет — для полного пути есть `razbor`.

Механика — в скрипте. За тобой: найти запись и показать человеку результат.

**Все команды ниже написаны от папки команд** — той, где лежит `meeting.py`. Её
точный путь на этой машине назван в подключении скилла: подставляй его, рабочая
папка у тебя может быть любой.

## Шаг 1. Запись

Файл назван человеком — бери его. Не назван — ищи:

```
python meeting.py find --date <ДД.ММ.ГГ>
```

Команда печатает, какую запись и какой источник имён нашла (локальная запись
Zoom кладёт `audio_only.m4a` и `transcript.txt` в одну папку с датой в имени), а
не найдя — где искала.

**Записи в облаке Zoom.** Спроси коннектор о записях за дату (`recordings_list`
с `from`/`to`). Дай человеку **ссылку `download_url` файла `M4A`** — скачать её
может только браузер, где он вошёл в свой аккаунт Zoom. Имена говорящих сохрани
отдельно: ответ `get_meeting_assets` по UUID встречи целиком в
`Разборы/<дата>/Zoom.json`. Без него спикеры выйдут безымянными («Спикер 1»).

## Шаг 2. Расшифровка

```
python meeting.py transcribe --date <ДД.ММ.ГГ>
```

Своё место для файлов — `--audio`, `--names`, `--out`. Готовая расшифровка
второй раз не заказывается: Deepgram платный, и `--force` переписывает файл,
переиспользуя уже оплаченный ответ.

Двое говорят в один микрофон — Zoom различает каналы, а не голоса, и подпишет
обоих владельцем канала. Кто есть кто, видно по репликам в `Deepgram raw.json`;
поправить — `--speaker 2=Анна`.

Подписи в расшифровке — те, под которыми люди сидят в Zoom. Свести их к
привычным именам раз и навсегда: файл `Имена.json` рядом со скриптами,
`{"Ivan Petrov": "Иван"}`. Файла нет — работает и так.

Одиночная запись без имён вовсе (диктофон, кусок разговора) — `python
transcribe.py "<файл или папка>"`.

## Шаг 3. Отдать человеку

Скажи, куда лёг файл, сколько в нём минут и кто в нём говорит. Дальше — по его
просьбе: пересказ, поиск по тексту, разбор задач командой `razbor`.

Ключ Deepgram — `DEEPGRAM_API_KEY` в `.env`. Нет ключа — скрипт скажет об этом
первой же строкой; регистрация бесплатная, кредита хватает надолго.
