# Расшифровка записи

Только текст. Задачи из разговора эта команда не извлекает и на сервер ничего не
отправляет — для полного пути есть `razbor`.

Механика — в скрипте. За тобой: найти запись и показать человеку результат.

**Все команды ниже написаны от папки команд** — той, где лежит `meeting.py`. Её
точный путь на этой машине назван в подключении скилла: подставляй его, рабочая
папка у тебя может быть любой.

## Шаг 1. Запись

Файл назван человеком — бери его. Не назван — спроси или посмотри, **где эта
запись: на компьютере или в облаке**. Zoom пишет куда велено, и по дате эти два
случая не различить: «на компьютере» — ищи на диске и в облако не ходи, «в
облаке» — иди туда, даже если на диске что-то нашлось (это может быть соседняя
встреча того же дня). Не сказано ничего — сначала диск, пусто — облако, и скажи
человеку, откуда взял.

**На компьютере:**

```
python meeting.py find --date <ДД.ММ.ГГ>
```

Команда печатает, какую запись и какой источник имён нашла, а не найдя — где
искала. Локальный Zoom кладёт запись в папку с датой в имени («2026-08-21
08.58.54 Планёрка Розница 9_00»); `transcript.txt` рядом бывает не всегда.

**В облаке, а на машине есть `../scripts/zoom_pull.py`** (он есть не везде — в
установочный пакет не входит) — забери запись сам, не гоняя человека в браузер:
`--json --date <ДД.ММ.ГГ>` покажет записи дня с временем и темой,
`--date <ДД.ММ.ГГ> --at <ЧЧ:ММ>` заберёт нужную. Несколько записей за день —
скрипт не выбирает сам, спрашивает время. Напечатанный им путь передавай в
расшифровку через `--audio`: тогда идёт именно та запись, а не «самая большая за
этот день».

**Имена говорящих — отдельная забота, и они есть почти всегда.** Их место —
`Разборы/<дата>/Zoom.json`: сохрани туда ответ коннектора Zoom ЦЕЛИКОМ, скрипт
разберёт его сам. Без имён спикеры выйдут как «Спикер 1», а восстанавливать
восьмерых по обращениям в тексте — полчаса ручной работы и ошибка в подписи.

- Запись писалась **на компьютер** (обычный режим): в облаке её нет, а встреча
  есть. `search_meetings` за дату → у нужной встречи `has_transcript: true` →
  `get_meeting_assets` по её UUID. Пустой `recordings_list` за эту дату НЕ
  значит «имён нет» — он значит только «облачной записи нет».
- Запись писалась **в облако**: `recordings_list` с `from`/`to`, дальше тот же
  `get_meeting_assets` по UUID. Сам файл к этому моменту уже забрал `zoom_pull`;
  скрипта на машине нет — тогда дай человеку **ссылку `download_url` файла
  `M4A`**, скачать её может только браузер, где он вошёл в свой аккаунт.
- Zoom положил `transcript.txt`/`.vtt` рядом с локальной записью — этого тоже
  хватает, сохранять ничего не надо.

## Шаг 2. Расшифровка

```
python meeting.py transcribe --date <ДД.ММ.ГГ>
```

Своё место для файлов — `--audio`, `--names`, `--out`. Готовая расшифровка
второй раз не заказывается: Deepgram платный, и `--force` переписывает файл,
переиспользуя уже оплаченный ответ.

Двое говорят в один микрофон или сидят под безымянным аккаунтом («Пользователь
Zoom») — Zoom различает каналы, а не голоса, и подпишет обоих одинаково.
Склейка сама скажет об этом строкой «одно имя … досталось спикерам N, M»:
посмотри их реплики в `Deepgram raw.json` и поправь — `--speaker 2=Анна`.

Подписи в расшифровке — те, под которыми люди сидят в Zoom. Свести их к
привычным именам раз и навсегда: файл `Имена.json` рядом со скриптами,
`{"Ivan Petrov": "Иван"}`. Файла нет — работает и так.

Одиночная запись без имён вовсе (диктофон, кусок разговора) — `python
transcribe.py "<файл или папка>"`.

## Шаг 3. Отдать человеку

Скажи, куда лёг файл, сколько в нём минут и кто в нём говорит. Дальше — по его
просьбе: пересказ, поиск по тексту, разбор задач командой `razbor`.

Ключ Deepgram — `DEEPGRAM_API_KEY` в `.env`. Нет ключа — скрипт скажет об этом
первой же строкой; регистрация бесплатная, кредита хватает надолго.
