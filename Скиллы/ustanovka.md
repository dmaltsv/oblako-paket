# Установка пакета

Человек напротив — **руководитель отдела, а не программист**. Он получил папку и
открыл тебя в ней. Твоя работа — довести его до рабочего состояния, ничего не
требуя читать и не заставляя ничего набирать в терминале.

**Все команды ниже написаны от папки команд** — той, где лежит `meeting.py`. Её
точный путь на этой машине назван в подключении скилла: подставляй его, рабочая
папка у тебя может быть любой.

## Как себя вести

- **Программы ставишь ТЫ, а не он.** Python и git — твоя работа: скажи одной
  фразой, что ставишь, и ставь. Не спрашивай разрешения на каждый шаг и не
  предлагай человеку «скачать с сайта», пока не убедился, что автоматический путь
  не сработал.
- **Человек делает только то, что за него сделать нельзя:** регистрации, кнопки
  в чужих кабинетах, настройки Zoom в его аккаунте, создание группы в Telegram.
  Таких мест ровно четыре, и каждое отмечено словом **«его руками»**.
- **Меньше слов, больше сделанного.** Каждый шаг заканчивается запущенной
  командой, а не обещанием.
- **Термин — объяснить одной фразой** при первом употреблении. «Ключ» — длинная
  строка-пароль, «`.env`» — файл с настройками рядом со скриптами.
- **Ключи в чат не проси.** Пусть вставляет сам в файл: сказанное в чате
  остаётся в переписке. Сказал всё-таки в чате — не повторяй его в ответе, не
  пиши в другие файлы и попроси на всякий случай выпустить новый.
- **Не останавливайся на первом «нет».** У шага 7 (Zoom) есть полноценный
  запасной путь, и провал там — не провал установки.
- **Считай шаги вслух.** «Сделали 4 из 10» после каждого — человеку нужно видеть
  край.
- **Никогда не говори «готово» словами.** Готовность показывает шаг 9.
- **Пути называй полностью.** Рабочая папка у тебя может быть не та; `.env`,
  созданный не в папке команд, проверка не найдёт, а ошибка выйдет молчаливой.

## Шаг 0. Где мы

Запусти проверку — она же скажет, чего не хватает, и после каждого шага её можно
звать снова:

```
python setup_check.py --offline
```

Не запустилась вовсе, потому что Python не найден, — это нормально в начале, иди
на шаг 1. Запустилась — по её списку и иди: отмеченное `[ок]` не повторяй.

Скажи человеку одной фразой: сколько шагов всего и что почти всё сделаешь сам.

## Шаг 1. Python — ставишь сам

Python — программа, которая исполняет эти скрипты. Зависимостей у пакета нет,
поэтому кроме самого Python ставить нечего.

Проверь, есть ли он и не слишком ли стар (нужен 3.10 или новее):

```
python --version
py --version
python3 --version
```

Нет или старее 3.10 — **ставь сам, не спрашивая**:

- **Windows:**
  ```
  winget install --id Python.Python.3.12 -e --accept-package-agreements --accept-source-agreements
  ```
- **macOS:** `python3` обычно уже стоит. Нет — `brew install python@3.12`, а без
  brew скачай установщик с https://www.python.org/downloads/ и запусти его.

**Предупреди человека заранее об одном:** система может показать окно «Разрешить
приложению внести изменения?» — нажать «Да» может только он, у тебя такой
возможности нет. Это единственное, чего не обойти.

`winget` отсутствует или отказал — тогда и только тогда ссылка
https://www.python.org/downloads/, кнопка «Download Python», и **на Windows
обязательно** галочка «Add python.exe to PATH» на первом экране установщика.
Без галочки не заработает ничего, и это самая частая поломка установки.

**После установки Python в этом окне может быть не виден** — оно помнит старое
окружение. Попроси **закрыть и открыть заново** окно, где ты запущен, и скажи,
чем продолжить: «настрой пакет, я на шаге 2».

## Шаг 2. git и обновляемость папки — тоже сам

git — программа, которой пакет получает свежие версии. Без неё команда «обнови
пакет» работать не будет, и через месяц человек застрянет на «сначала обновите
пакет».

```
git --version
```

Нет — ставь сам: **Windows** `winget install --id Git.Git -e
--accept-package-agreements --accept-source-agreements`; **macOS**
`xcode-select --install` (откроется окно, «Установить» нажимает он) или
`brew install git`.

Теперь проверь, обновляемая ли папка:

```
git -C "<папка команд>" remote -v
```

**Ответ есть и в нём `oblako-paket`** — папку клонировали, всё в порядке.

**`not a git repository`** — папку принесли архивом. Сделай её обновляемой на
месте, ничего не перенося:

```
git -C "<папка команд>" init -b master
git -C "<папка команд>" remote add origin https://github.com/dmaltsv/oblako-paket.git
git -C "<папка команд>" fetch origin
git -C "<папка команд>" reset --hard origin/master
git -C "<папка команд>" branch --set-upstream-to=origin/master master
```

`reset --hard` выравнивает папку по свежей версии. Личное он не тронет: `.env` и
`Разборы/` в репозиторий не входят, а файлов вне него эта команда не касается.
Но **если человек сам правил скрипты** — сначала покажи `git -C "<папка>" status`
и спроси; молча затирать его правки нельзя.

## Шаг 3. Команды агенту

Инструкции лежат в папке `Скиллы/`, а клиент ищет их у себя. Соедини:

```
python install_skills.py
```

Затем **перезапусти клиента** (закрыть и открыть заново) — иначе он держит
старый список команд в памяти. Если перезапуск обрывает наш разговор, скажи об
этом заранее и назови, чем продолжить: «настрой пакет, я на шаге 4».

Перезапустить нечем или команды всё равно не видны — не тупик: читай нужный файл
из `Скиллы/` и исполняй напрямую.

## Шаг 4. Ключ Deepgram — расшифровка записи (его руками)

Deepgram превращает запись встречи в текст. Ключ у каждого руководителя **свой**:
общей оплаты нет. При регистрации дают стартовый кредит $200 — этого хватает
примерно на 190 полуторачасовых встреч, то есть на очень долго; карта для начала
не нужна. Одна встреча стоит около доллара, расход виден в том же кабинете.

Проведи по шагам, дожидаясь каждого:

1. https://console.deepgram.com — регистрация через Google или почту.
2. Слева «API Keys» → «Create a New API Key».
3. **Ключ показывается один раз** — скопировать сразу, не закрывая окно.

Скажи: вставлять его будем в файл на шаге 6, в чат присылать не нужно.

## Шаг 5. Ключ доступа к серверу (его руками)

Этот ключ пускает пакет к серверу Oblako и больше никуда: доступа к самой машине
сервера у него нет, только три операции разбора планёрки.

1. Открыть Mini App Oblako в Telegram → «Ещё» → «Настройки» → кнопка «Ключ
   доступа».
2. Ключ показывается **один раз**; живой ключ у человека один — выдача нового
   отзывает прежний, и старый перестаёт работать.

Кнопки нет вовсе — значит система пока не считает его руководителем отдела.
Сам он это не исправит: скажи ему написать владельцу системы, а установку
продолжай — остальные шаги от ключа не зависят.

Адрес сервера ключом не выдаётся, его говорит владелец системы вместе с
приглашением. Не знает — пусть спросит; без адреса дальше не пройти.

## Шаг 6. Записать три строки в `.env`

`.env` — файл настроек рядом со скриптами. Его заводит сама проверка (шаг 0),
если файла не было, и печатает полный путь — бери путь оттуда.

Открой файл человеку по этому пути (Windows — `notepad "<путь>"`, macOS —
`open -e "<путь>"`) и назови три строки, в которые вписать значения **после знака
`=`, без пробелов и без кавычек**:

- `OBLAKO_BASE_URL` — адрес сервера;
- `OBLAKO_ACCESS_KEY` — ключ из шага 5;
- `DEEPGRAM_API_KEY` — ключ из шага 4.

Скажи отдельно: **вставлять только в `.env`**. Рядом лежит `.env.example` —
пустой образец для других людей, ключам там не место.

Сохранить (Ctrl+S) и сказать тебе. Проверь сделанное:

```
python setup_check.py --offline
```

Файл `.env` в общий репозиторий не уезжает — так настроено с первого коммита,
ключи с этой машины никуда не уйдут.

## Шаг 7. Zoom — чтобы запись и имена появлялись сами

Разбору нужны две вещи от Zoom: **запись встречи** и **имена говорящих**. Имена
берутся либо из облачного timeline, либо из файла субтитров рядом с локальной
записью (`transcript.txt`, `closed_caption.txt` или `.vtt`).

**Названия пунктов в разных версиях Zoom отличаются — ищи по смыслу, а не по
буквам, и проверяй результатом, а не описанием.**

**Путь А — облако Zoom (пробуй первым).** Проверяй **прямо на этом компьютере**:
доступ к облачным записям упирается в права внутри аккаунта Zoom, и одного
платного тарифа может не хватить.

1. Zoom-коннектор подключён? Нет — проведи по подключению в клиенте.
2. Спроси у коннектора записи за последний месяц (`recordings_list` с
   `from`/`to`). Приехал список — путь А работает, скажи об этом.
3. Ошибка, пусто или коннектора нет вовсе — **спокойно переходи к пути Б**. Так
   бывает, это не поломка.

**Путь Б — локальная запись (надёжный, работает всегда).** Проведи человека по
настройкам Zoom (его руками, ты подсказываешь каждый пункт):

1. Zoom → «Настройки» → «Запись».
2. Включить **локальную запись**.
3. Включить **автоматический старт записи при начале встречи** — пункт в том же
   разделе, смысл «записывать автоматически, как только я начинаю встречу». Это
   ключевая настройка: без неё он однажды забудет нажать «Запись», и разбирать
   будет нечего.
4. Включить **сохранение расшифровки/субтитров в файл** — в разных версиях это
   «записывать субтитры», «сохранять расшифровку», «audio transcript». Именно
   этот файл даёт имена говорящих.
5. Посмотреть, **куда Zoom кладёт записи** (в том же разделе указана папка).

**Проверь результатом, а не словами:** попроси начать встречу «с самим собой» на
20 секунд, сказать пару фраз и закончить. Затем:

```
python meeting.py find
```

Команда печатает, какую запись и какой источник имён нашла. Нашла запись и
источник имён — путь Б настроен. Нашла только запись — не хватает пункта 4,
вернись к нему. Не нашла ничего — папка нестандартная: впиши её в
`OBLAKO_AUDIO_DIRS` в `.env` (несколько папок — через `;`) и повтори.

**Скажи вслух и не пропускай:** записи в облаке Zoom живут **около месяца**. Не
разобрал планёрку за месяц — записи больше нет, и восстановить её нечем.

## Шаг 8. Групповой чат отдела (его руками)

Итог разбора публикуется в групповом чате отдела. Чата нет — разбор дойдёт до
задач, но итог публиковать будет некуда, и человек увидит ошибку в конце самой
первой планёрки. Поэтому **спроси прямо сейчас**: есть ли у отдела групповой чат
в Telegram?

**Есть** — проведи по привязке:

1. Добавить в этот чат бота Oblako (в чате: «Добавить участника» → найти бота).
2. Написать в чате команду `/setchat`. Ведёт несколько отделов — `/setchat
   <номер или имя отдела>`; номера он видит в Mini App на экране «Команда».
3. **Бот отвечает в тот же чат** — попроси прочитать ответ вслух:
   - «✅ Отдел «…» теперь получает утреннюю сводку в этот чат» — готово;
   - «Отдел «…» и так получает сводку в этот чат» — было привязано раньше, тоже
     готово;
   - «⚠️ Сообщение отправлено от имени группы…» — в чате включена анонимность
     администраторов, из-за неё не видно, кто пишет: выключить и повторить;
   - «⚠️ Вас нет в системе…» — он ещё не заведён как руководитель, это к
     владельцу системы;
   - «⚠️ …» с другим текстом — прочитай причину и действуй по ней.

**Нет** — помоги создать (это две минуты, делает он на телефоне):

1. Telegram → «Новая группа».
2. Добавить людей отдела и бота Oblako.
3. Назвать группу по отделу.
4. Написать в ней `/setchat` и прочитать ответ бота — как выше.

**Отказался заводить чат** — не настаивай, но скажи прямо: разбор будет
работать, задачи людям дойдут, а итог в группу не опубликуется, и в конце
разбора появится сообщение об этом. Пометь это как незакрытый пункт и назови его
ещё раз на шаге 10.

## Шаг 9. Проверка целиком и пробный прогон

Теперь полностью, уже с сетью:

```
python setup_check.py
```

Она сходит на сервер живым запросом: адрес, ключ, права, состав людей и версия
формата — за один раз. Что бывает и что делать:

| Ответ проверки | Что это | Что делать |
|---|---|---|
| ключ отозван / доступ запрещён | ключ старый или скопирован не полностью | выпустить новый (шаг 5) и вписать целиком |
| «не выгрузка Oblako» | адрес ведёт не туда | уточнить адрес у владельца |
| «сервер ушёл вперёд» | пакет устарел | команда «обнови пакет», потом проверка снова |
| «не видно ни одного человека» | отдел ещё не заведён | сказать владельцу системы |

Всё зелёное — пробный прогон, он ничего никуда не отправляет:

```
python meeting.py status
python meeting.py find
```

Первая скажет, на каком шаге разбор за сегодня (его нет — так и скажет), вторая
покажет, где будет искать запись. Ошибки тут нормальны, если встречи сегодня не
было: важно, что команды запускаются и отвечают по-русски.

## Шаг 10. Урок: как пройдёт первая планёрка

**Установка кончается не словами «всё готово», а этим:**

```
python setup_check.py
```

Скажи прямо: «эту команду можно запускать в любой день — она заново проверяет
всё, а не вспоминает вчерашнее».

Потом — короткий урок. Проговори своими словами, но обязательно все пять
пунктов:

1. **Одна фраза на всё** — «разбери планёрку». Больше ничего запоминать не надо.
2. **Что произойдёт:** найду запись, расшифрую (несколько минут на часовую
   встречу), возьму с сервера свежие задачи его людей, покажу разбор по людям —
   кому что.
3. **Слово, которое всё запускает.** Он смотрит разбор, правит словами сколько
   угодно: формулировки, сроки, что-то убрать совсем. Когда всё верно — говорит
   ровно **«запиши»**. Слова «ок», «хорошо», «согласен» командой не считаются, и
   это сделано нарочно: так задачи не уедут людям от случайно сказанной фразы.
4. **Что будет после «запиши»:** задачи лягут людям в списки, каждому придёт
   уведомление в боте, итог опубликуется в чате отдела.
5. **Записи Zoom живут около месяца** — разбирать лучше в тот же день.

Отдельно назови, каким путём у него берётся запись (облако или локальная папка),
и повтори незакрытые пункты, если они есть: не выданный ключ доступа, не
привязанный чат отдела.

Дальше его первая настоящая команда — «разбери планёрку». В первые три раза я
буду объяснять каждый шаг подробно, потом перейду на короткий разговор.

## После установки. Предложи: ссылки на созвоны могут заводиться сами

Установка кончена, и об этом скажи прямо — дальше необязательное, отдельное от
разбора планёрок.

**Что предложить, простыми словами:** «Сейчас ссылку на созвон вы вписываете во
встречу руками, а приглашение людям уходит раньше, чем вы успеете её вписать.
Это можно включить: Oblako будет заводить отдельную комнату Zoom на каждую вашу
встречу сам, до того как уйдут приглашения. Перенесли встречу — комната
переехала, отменили — убралась».

**Кому подходит:** у кого свой аккаунт Zoom и он в нём владелец. Платный тариф
желателен — на бесплатном созвон обрывается на 40 минутах.

**Сколько займёт:** минут десять, из них его участие — одна минута: три строки
ключа он вставляет сам, читать и вводить их за него нельзя.

Спроси, делать сейчас или в другой день. Обе ветки нормальны:

- **сейчас** — открой `Ключ Zoom — как завести его себе.md` в этой же папке и
  веди человека по нему: там шесть шагов и своя проверка;
- **потом** — скажи, что файл лежит рядом и вернуться можно в любой день:
  открыть помощника в этой папке и сказать «проведи меня по файлу про ключ
  Zoom».

**Отказ — не провал установки, и звучать это должно так же.** Без ключа встречи
не остаются без ссылок: её вписывает руками любой участник встречи, у кого Zoom
есть, а свою постоянную комнату можно один раз вписать в настройках Oblako — она
работает на любом тарифе, включая бесплатный.

**Ключ завели — спроси про записи, но только если он пишет планёрки в ОБЛАКО.**
Тому же ключу добавляются два права, и тогда запись из облака ты забираешь сам,
а не даёшь человеку ссылку и ждёшь, пока он скачает. Задание — соседний файл
`Записи Zoom — чтобы помощник забирал их сам.md`, там три шага. Пишет на
компьютер (шаг 7, путь Б) — не предлагай вовсе: файл и так лежит на диске.

Разнесено по двум файлам нарочно, и это стоит сказать вслух: права на записи
открывают ключу разговоры компании целиком, а права на встречи — нет. Человек
решает про них отдельно, а не берёт заодно.
