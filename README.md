# Пакет Oblako — разбор планёрки на своём компьютере

Расшифровка встречи и разбор договорённостей: задачи из разговора уезжают в
списки людей, итог — в групповой чат отдела. Всё делается **командами агенту**
(Claude Code или Codex), открытому в этой папке.

**Человеку хватит файла `НАЧНИ ОТСЮДА.md`** — одна страница, одна фраза, дальше
ведёт сам агент. Этот файл — запасной путь: он нужен, если мастер споткнулся или
хочется понять, что происходит.

## Как получить папку

Есть git — одной командой (так работает и обновление):

```
git clone https://github.com/dmaltsv/oblako-paket.git Oblako
```

Нет git — скачать архив и распаковать:
https://github.com/dmaltsv/oblako-paket/archive/refs/heads/master.zip

Архив тоже годится: мастер установки сам поставит git и сделает папку
обновляемой, ничего не перенося.

## Настройка — одна фраза

Открой в папке Claude Code или Codex и скажи **«настрой пакет»**. Мастер проверит
и при необходимости поставит Python и git, проведёт по ключам и настройкам Zoom,
поможет привязать групповой чат и закончит проверкой.

Команды агенту он подключит сам; вручную это `python install_skills.py` (после
него клиента надо перезапустить).

## Четыре команды агенту

| Скажи | Что будет |
|---|---|
| «настрой пакет» | установка с нуля: программы, ключи, Zoom, чат отдела, проверка |
| «разбери планёрку» | весь путь: запись → расшифровка → задачи → чат отдела |
| «расшифруй запись» | только текст встречи с именами говорящих |
| «обнови пакет» | свежая версия и проверка, что всё работает |

**Записи в облаке Zoom живут около месяца.** Не разобрал планёрку за месяц —
записи больше нет, и восстановить её нечем. Это не настройка и не ошибка, это
правило Zoom.

## Проверка установки — в любой день

```
python setup_check.py
```

Она не вспоминает вчерашнее, а проверяет заново: Python, файл настроек, ключ
Deepgram (спрашивает кабинет), папки, команды агенту, живую связь с сервером и
совпадение версий. Ответ — список строк `[ок]` и `[нет]`, у каждой `[нет]` есть
следующий шаг. `--offline` — то же самое без сети.

## Что нужно один раз

**1. Python и git** — ставит мастер установки. Руками: Python с
https://www.python.org/downloads/ (на Windows **обязательно** галочка «Add
python.exe to PATH»), git с https://git-scm.com. Больше ничего не нужно:
зависимостей у пакета нет.

**2. Ключ Deepgram** (расшифровка) — https://console.deepgram.com, регистрация
через Google или почту, слева «API Keys» → «Create a New API Key». Ключ
показывается **один раз**. Ключ **свой у каждого руководителя**: общей оплаты
нет. При регистрации дают $200 стартового кредита — это примерно 190
полуторачасовых встреч, карта для начала не нужна; одна встреча стоит около
доллара.

**3. Ключ доступа к серверу** — кнопка «Ключ доступа» в настройках Mini App,
показывается **один раз**. Живой ключ у человека один: выдача нового отзывает
прежний. Ключ даёт ровно три операции разбора планёрки и ничего больше —
доступа к машине сервера у пакета нет.

**4. Адрес сервера** — его говорит владелец системы. Ключом он не выдаётся.

**5. Записать всё в `.env`** — скопировать `.env.example` рядом под именем
`.env` и заполнить три строки:

```
OBLAKO_BASE_URL=https://<адрес сервера>
OBLAKO_ACCESS_KEY=<личный ключ доступа>
DEEPGRAM_API_KEY=<свой ключ Deepgram>
```

Ключи вписывать **только в `.env`**: `.env.example` — пустой образец, он уезжает
в общее хранилище. Необязательное: `OBLAKO_AUDIO_DIRS` — свои папки с записями
через `;`. Без него смотрим в «Документы/Zoom», «Zoom», «Загрузки».

`.env` в репозиторий не уезжает — так настроено с первого коммита.

**6. Имена говорящих (по желанию)** — Zoom подписывает участников так, как они
назвали себя в своих аккаунтах. Свести подписи к привычным именам раз и навсегда:
файл `Имена.json` рядом со скриптами, `{"Ivan Petrov": "Иван", "ivanp": "Иван"}`.
Файла нет — работает и так, просто подписи в расшифровке длиннее. В хранилище
этот файл не уезжает: состав команды — личное дело каждого.

**7. Ключ Zoom (по желанию, к разбору не относится)** — от него ссылка на созвон
перестаёт вписываться руками: Oblako заводит отдельную комнату Zoom на каждую
вашу встречу сам, до того как уйдут приглашения. Нужен свой аккаунт Zoom, где вы
владелец. Всё задание — в файле `Ключ Zoom — как завести его себе.md` рядом;
оно написано для помощника, откройте его и скажите «проведи меня по файлу про
ключ Zoom». Без ключа встречи тоже не остаются без ссылок: её вписывает любой
участник встречи, у кого Zoom есть.

## Откуда берётся запись

Два равноправных пути; какой из них у тебя, показывает мастер установки.

- **Облако Zoom** — агент спрашивает Zoom-коннектор и даёт ссылку на файл `M4A`;
  скачать её может только браузер, где ты вошёл в свой аккаунт Zoom.
- **Локальная запись** — Zoom → «Настройки» → «Запись»: включить локальную
  запись, автоматический старт записи при начале встречи и сохранение
  расшифровки в файл. Файлы лягут в «Документы/Zoom», и этого достаточно: имена
  говорящих есть и там.

Облако может не подняться — доступ к записям упирается в права внутри аккаунта
Zoom, а не только в тариф. Тогда работает локальный путь, и это нормально.

## Если что-то не так

- **«Python not found»** — Python не установлен или при установке не была
  поставлена галочка «Add python.exe to PATH». Переустановить с ней.
- **«не найден ключ DEEPGRAM_API_KEY»** — ключа нет ни в окружении, ни в `.env`.
- **Deepgram отвечает 401 или 403** — ключ неверный или скопирован не полностью.
- **«Нет ключа доступа» / «Ключ доступа испорчен»** — выпустить новый кнопкой в
  настройках Mini App и вставить целиком (кириллическая буква вместо латинской —
  обычная цена копирования).
- **«сначала обновите пакет» / «сервер ушёл вперёд»** — скажи агенту «обнови
  пакет».
- **«отстал сервер»** — обратный случай, и он не твой: скажи владельцу системы.
- **Сервер отказал (код 2)** — сообщение называет причину: чужой отдел,
  устаревший снимок, непрошедший проверку пакет. Сервер отвергает пакет целиком,
  до единой записи в базу.
- **Сервер не ответил (код 3)** — сеть или сервер; повторить безопасно.

## Что здесь лежит

```
НАЧНИ ОТСЮДА.md     одна страница для человека: одна фраза и что подготовить
Ключ Zoom — как завести его себе.md   задание помощнику: ссылки на созвоны сами
Скиллы/              четыре команды агенту, тексты инструкций
install_skills.py    подключение этих команд к Claude Code и к Codex
setup_check.py       повторяемая проверка установки
meeting.py           механика разбора: где мы, что дальше, гейт «запиши»
zoom_deepgram_merge.py  расшифровка со сшитыми именами говорящих (Deepgram + Zoom)
transcribe.py        одиночная расшифровка без имён (диктофон, кусок разговора)
oblako_client.py     общая половина клиентов: .env, ключ, HTTP, TLS, коды выхода
fetch_tasks.py       выгрузка своих людей и их открытых задач перед планёркой
send_package.py      сдача разбора планёрки и досдача итога в чат отдела
.env.example         образец настроек            ВЕРСИЯ   версия сборки
Имена.json           подписи Zoom -> имена людей (личное, в git не едет)
Разборы/             разборы встреч (в git не едут)
Аудио/               запасное место для записи (в git не едет)
```

Кода сервера здесь нет и не будет. Ручная работа — теми же скриптами напрямую:

```
python meeting.py status  --date <ДД.ММ.ГГ>          где мы и что дальше
python meeting.py find    --date <ДД.ММ.ГГ>          какая запись нашлась
python meeting.py transcribe --date <ДД.ММ.ГГ>       расшифровка с именами
python meeting.py tasks   --date <ДД.ММ.ГГ> [--team <отдел>]
python meeting.py preview --date <ДД.ММ.ГГ>          превью и сверка со снимком
python meeting.py confirm --date <ДД.ММ.ГГ> --word "запиши"
python meeting.py send    --date <ДД.ММ.ГГ> --team <отдел>
python meeting.py send    --date <ДД.ММ.ГГ> --team <отдел> --no-publish
                                                       у отдела нет группы: без итога в чате
python meeting.py publish --date <ДД.ММ.ГГ> --team <отдел>    досдать итог
```

Состояние разбора живёт в файлах папки `Разборы/<ДД.ММ.ГГ>/`, поэтому повторный
запуск ничего не переделывает, а прерванный разбор продолжается с того же места
хоть завтра.

Windows и macOS — один и тот же путь. Подробности каждого скрипта — в его шапке,
коды выхода — в шапке `oblako_client.py`.
