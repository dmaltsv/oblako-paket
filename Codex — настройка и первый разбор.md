# Если ваш помощник — Codex

Эта страница для тех, кто открывает пакет в **Codex** (помощник ChatGPT), а не в
Claude Code. Почти всё работает так же, как написано в `НАЧНИ ОТСЮДА.md`; ниже —
чем Codex отличается, как его настроить и как проверить всё целиком: от записи в
Zoom до задач людям в Telegram.

## Что работает, а чего нет

**Работает всё, ради чего пакет ставят:** «разбери планёрку», «разбери встречу»,
«расшифруй запись», «подготовься к совету», «собери повестку», «поставь задачу»,
срез «что сделал отдел за неделю», «обнови пакет», «проверь установку».

**Чего в Codex нет — и это не поломка:**

- **Автомата.** Автоматический запуск после Zoom («запись готова — расшифровка
  пришла сама») есть только в Claude Code с подпиской claude.ai. В Codex после
  встречи вы сами говорите помощнику «разбери планёрку» — дальше всё то же самое.
- **Доступа к вашему браузеру.** Claude Code умеет сам нажимать кнопки в
  настройках Zoom; Codex — нет. Эти места вы проходите своими руками, помощник
  подсказывает каждый пункт словами. Установка от этого дольше минут на десять.
- **Второй проверки слова «отправляй».** В Claude Code отдельный сторож следит,
  что «отправляй» сказали именно вы. В Codex слово проверяет только сам разбор.
  Поэтому говорите «отправляй» сами и не просите помощника «отправить самому».

**Сервер Oblako переделывать не нужно, и его код не нужен.** Пакет ходит на
сервер только по вашему личному ключу доступа. Если Codex просит код сервера,
доступ к нему или хочет «подключить облачного агента OpenAI» — он пытается
построить автомат. Остановите его фразой: «автомата в Codex нет, работаем через
компьютер — по `AGENTS.md`».

## Что нужно до начала

- **Codex** на компьютере, вход своей учётной записью ChatGPT.
- **Zoom**, где вы проводите планёрку и можете включить запись. Запись на
  компьютер работает на любом тарифе; запись в облако — на платном.
- **Oblako в Telegram**, и вы в нём руководитель отдела.

## Установка — около 40 минут, ваших из них — минут пятнадцать

1. **Папка пакета.** Есть git — `git clone https://github.com/dmaltsv/oblako-paket.git`;
   нет — архив <https://github.com/dmaltsv/oblako-paket/archive/refs/heads/master.zip>,
   распаковать. Папку потом не переносить: к ней привязываются команды помощника.
2. **Открыть Codex в этой папке и сказать: «настрой пакет».** Помощник сам
   поставит Python и git и подключит свои команды. После этого он попросит
   **закрыть и открыть Codex заново** — иначе он не увидит новых команд. Открыли
   снова — скажите «настрой пакет» ещё раз, он продолжит с того же места.
3. **Ключ Deepgram — вашими руками.** Deepgram превращает запись в текст.
   <https://console.deepgram.com> → регистрация через Google → «API Keys» →
   «Create a New API Key». Дают $200 стартового кредита — это около 190
   полуторачасовых встреч; карта не нужна. Ключ показывается один раз.
4. **Ключ доступа к серверу — вашими руками.** Oblako в Telegram → «Ещё» →
   «Настройки» → «Ключ доступа». Показывается один раз; выдача нового отменяет
   прежний. Кнопки нет — напишите владельцу системы.
5. **Адрес сервера** скажет владелец системы.
6. **Файл настроек `.env`.** Помощник откроет его вам на экране. Вы вписываете
   три строки после знака `=` — без пробелов и кавычек:
   `OBLAKO_BASE_URL` (адрес), `OBLAKO_ACCESS_KEY` (ключ из п. 4),
   `DEEPGRAM_API_KEY` (ключ из п. 3). **Ключи — только в этот файл, в
   переписку с помощником их не вставлять.**
7. **Zoom — вашими руками, помощник подскажет пункты.** Без автомата проще
   **запись на компьютер**: файл сразу лежит на диске, ключ Zoom не нужен. В
   настройках Zoom → «Запись»: включить локальную запись, автоматический старт
   записи при начале встречи и сохранение расшифровки/субтитров в файл (из него
   берутся имена говорящих). Пишете в облако — тоже можно, помощник проведёт
   по своему пути.
8. **Чат отдела — вашими руками.** Добавить бота Oblako в групповой чат отдела и
   написать там `/setchat`. Бот ответит «✅ Отдел … теперь получает…» — готово.
   Туда уходит итог планёрки.
9. **Библиотека (общие документы на GitHub)** — по желанию, для разбора не
   обязательна. Помощник проведёт, если скажете.
10. **Проверка.** Помощник запустит `python setup_check.py`. Всё зелёное —
    установка закончена. Есть красное — у каждой строки назван следующий шаг.

## Пробный прогон — от записи до задач в Telegram

1. **Короткая встреча в Zoom с записью** — минут пять, можно вдвоём с
   коллегой из отдела. Скажите вслух одно-два поручения: «Арина, до пятницы
   сверка остатков по кассе». Поручайте себе или тому, кто знает о пробе.
2. **Закончите встречу** и подождите, пока Zoom допишет запись (на компьютер —
   минута-две).
3. **Скажите помощнику: «разбери планёрку».** Он найдёт запись, расшифрует её,
   возьмёт с сервера свежие задачи ваших людей и покажет разбор: кому какая
   задача и с каким сроком.
4. **Поправьте словами** всё, что нужно: формулировку, срок, лишний пункт.
5. **Скажите ровно: «отправляй».** «Ок» и «да» командой не считаются — нарочно.
6. **Проверьте результат:** задача пришла человеку в Telegram, итог — в чате
   отдела. Пробную задачу потом можно снять в Oblako.

Разбирать встречу не в тот же день — назовите дату: «разбери планёрку за
вчера». Записи в облаке Zoom живут около месяца.

## Если что-то пошло не так

| Что видно | Что сказать помощнику |
|---|---|
| Непонятно, что сломалось | «проверь установку» |
| Codex не знает команды «настрой пакет» или «разбери планёрку» | «прочитай `AGENTS.md` в папке пакета и действуй по нему» |
| Сервер ответил «сначала обновите пакет» | «обнови пакет» |
| Codex просит код или доступ к серверу | «автомата в Codex нет, работаем через компьютер — по `AGENTS.md`» |

## Для помощника (Codex)

- Точка входа — `AGENTS.md`, команды — `Скиллы/`. Исполняй их как написано;
  блоки «только для Claude Code» (Claude in Chrome, автомат) пропускай.
- **Автомата нет.** `Скиллы/avtomat.md` дальше шага 0 не исполняй. Сервер
  Oblako не меняй, его кода и доступа к нему не проси: пакет работает с
  сервером только по `OBLAKO_ACCESS_KEY`.
- **Сторожа слова нет.** В `--word` передавай последнее сообщение человека
  дословно; сам слово не подставляй и не пересказывай.
- Ключи в чат не проси и не повторяй — человек вписывает их в `.env` сам.
